展开折叠

ExpandableTable 在表格最左侧添加展开/折叠图标列，点击后在对应行下方插入展开详情行， 用于展示行的详细信息。展开内容通过 expandRenderer 自定义渲染。

基础用法

定义列、数据，并通过 expandRenderer 渲染展开内容：

data class Order(val id: String, val customer: String, val amount: Int, val address: String)

ExpandableTable<Order> {
    attr {
        columns = listOf(
            column("订单号", flex = 2f) { it.id },
            column("客户", flex = 2f) { it.customer },
            column("金额", flex = 1f, align = TableCellAlign.RIGHT) { it.amount.toString() },
        )
        data = orders
        expandRenderer = { order ->
            View {
                attr { flexDirectionColumn(); padding(8f, 12f, 8f, 12f) }
                Text { attr { text("收货地址: ${order.address}"); fontSize(13f) } }
                Text { attr { text("订单详情: 共 3 件商品"); fontSize(13f); marginTop(4f) } }
            }
        }
    }
    event {
        expandChanged { index, expanded ->
            println("行 $index ${if (expanded) "展开" else "折叠"}")
        }
    }
}

自定义展开图标

通过 expandIcon 和 collapseIcon 自定义展开/折叠状态的图标文本：

ExpandableTable<Order> {
    attr {
        columns = orderColumns
        data = orders
        expandIcon = "＋"      // 折叠态图标
        collapseIcon = "－"    // 展开态图标
        expandColumnWidth = 40f // 图标列宽度
        expandRenderer = { order ->
            Text { attr { text("详细信息: ${order.id}"); fontSize(13f) } }
        }
    }
}

固定展开行高度

设置 expandRowHeight 为固定值，确保展开行高度一致：

ExpandableTable<Order> {
    attr {
        columns = orderColumns
        data = orders
        expandRowHeight = 80f  // 固定展开行高度
        expandRenderer = { order ->
            View {
                attr { flexDirectionColumn(); padding(8f) }
                Text { attr { text("地址: ${order.address}") } }
                Text { attr { text("备注: 请尽快发货"); marginTop(4f) } }
            }
        }
    }
    event {
        rowClick { item, index ->
            println("点击订单: ${item.id}")
        }
    }
}

属性类型默认值说明

collapseIconString"▼"展开态图标文本
expandRowHeightFloat0f（自动）展开行高度，0 表示自动高度

分页

PaginatedTable 对全量数据自动进行 subList 切片分页，并在表格下方渲染分页导航栏 （上一页 / 页码 / 下一页 / 总条数）。支持自定义每页条数和页码变化回调。

基础用法

传入全量数据，设置 pageSize，即可自动分页：

data class Student(val name: String, val age: Int, val score: Int)

// 50 条数据
val allStudents = (1..50).map {
    Student("学生$it", 16 + it % 4, 60 + it % 40)
}

PaginatedTable<Student> {
    attr {
        data = allStudents
        columns = listOf(
            column("姓名", flex = 2f) { it.name },
            column("年龄", flex = 1f, align = TableCellAlign.CENTER) { it.age.toString() },
            column("成绩", flex = 1f, align = TableCellAlign.RIGHT) { it.score.toString() },
        )
        pageSize = 10
        theme = TableTheme.BORDERED
    }
    event {
        pageChanged { page -> println("切换到第 $page 页") }
    }
}

自定义每页条数选项

通过 pageSizeOptions 提供可选的每页条数列表：

PaginatedTable<Student> {
    attr {
        data = allStudents
        columns = studentColumns
        pageSize = 20
        pageSizeOptions = listOf(10, 20, 50, 100)
        theme = TableTheme.STRIPE
    }
    event {
        pageChanged { page -> viewModel.onPageChanged(page) }
        pageSizeChanged { size -> viewModel.onPageSizeChanged(size) }
    }
}

配合表格样式

通过 tableInit 回调对内部表格进行额外配置（如排序、选择等）：

PaginatedTable<Student> {
    attr {
        data = allStudents
        columns = studentColumns
        pageSize = 10
        tableInit = {
            attr {
                sortable = true
                selectable = true
                stickyHeader = true
            }
            event {
                rowClick { item, index ->
                    println("点击: ${item.name}")
                }
            }
        }
    }
}

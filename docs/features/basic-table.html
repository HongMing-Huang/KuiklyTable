基础表格

基础表格是 KuiklyTable 最核心的入口。你只需定义一个数据类，声明列配置，传入数据列表， 即可用极简的 Kotlin DSL 语法渲染出一个功能完整的跨平台表格。

最简示例

只需三列文本列，传入 data 即可：

data class Student(val name: String, val age: Int, val score: Int)

val students = listOf(
    Student("张三", 18, 92),
    Student("李四", 17, 85),
    Student("王五", 16, 78),
)

Table<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f) { it.name },
            column("年龄", flex = 1f, align = TableCellAlign.CENTER) { it.age.toString() },
            column("成绩", flex = 1f, align = TableCellAlign.RIGHT) { it.score.toString() },
        )
        data = students
    }
}

指定主题

通过 theme 属性切换表格风格，默认为 TableTheme.DEFAULT（仅底部分隔线）：

Table<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f) { it.name },
            column("分数", flex = 1f, align = TableCellAlign.RIGHT) { it.score.toString() },
        )
        data = students
        theme = TableTheme.BORDERED  // 全边框主题
    }
}

行点击事件

通过 event {} DSL 块注册行点击回调：

Table<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f) { it.name },
            column("成绩", flex = 1f) { it.score.toString() },
        )
        data = students
    }
    event {
        rowClick { item, index ->
            println("点击了第 ${index + 1} 行：${item.name}，成绩 ${item.score}")
        }
    }
}

核心概念

column() — 创建纯文本列，传入标题、弹性比例 flex、对齐方式 align， 以及一个将数据项转换为字符串的 lambda。
Table<T> — 泛型 DSL 入口，attr {} 配置属性，event {} 注册事件。
TableTheme — 内置 4 种主题，一行切换。

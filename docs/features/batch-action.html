批量操作

BatchActionTable 内部强制启用行选择功能，当有行被选中时，底部自动滑出批量操作栏， 展示已配置的操作按钮（如批量删除、批量导出）和取消按钮。通过 BatchAction 定义操作项。

基础用法

定义批量操作列表，点击行选中后底部出现操作栏：

data class Student(val name: String, val score: Int)

BatchActionTable<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f) { it.name },
            column("成绩", flex = 1f, align = TableCellAlign.RIGHT) { it.score.toString() },
        )
        data = students
        batchActions = listOf(
            BatchAction("批量删除", icon = "🗑") { indices ->
                println("删除 ${indices.size} 项: $indices")
                viewModel.deleteStudents(indices)
            },
            BatchAction("批量导出", icon = "📤") { indices ->
                println("导出 ${indices.size} 项")
                viewModel.exportStudents(indices)
            }
        )
        theme = TableTheme.BORDERED
    }
    event {
        batchAction { action, indices ->
            println("执行: ${action.label}，选中行: $indices")
        }
    }
}

自定义操作栏样式

通过样式属性自定义批量操作栏的外观：

BatchActionTable<Student> {
    attr {
        columns = studentColumns
        data = students
        batchActions = listOf(
            BatchAction("批量删除") { indices -> viewModel.delete(indices) },
            BatchAction("标记已读") { indices -> viewModel.markRead(indices) },
        )
        actionBarHeight = 56f
        actionBarBackgroundColor = Color(0xFFE8F5E9)
        actionBarTextColor = Color(0xFF333333)
        actionButtonTextColor = Color(0xFF4CAF50)
        cancelButtonTextColor = Color(0xFF999999)
        actionBarFontSize = 14f
    }
    event {
        selectionChanged { indices ->
            println("当前选中 ${indices.size} 项")
        }
    }
}

配合表格样式

通过 tableInit 对内部表格进行额外配置：

BatchActionTable<Student> {
    attr {
        columns = studentColumns
        data = students
        batchActions = listOf(
            BatchAction("批量删除") { indices -> viewModel.delete(indices) }
        )
        tableInit = {
            attr {
                sortable = true
                theme = TableTheme.STRIPE
            }
        }
    }
}

API 参考

属性类型默认值说明
dataList<T>emptyList()数据列表
columnsList<TableColumn<T>>emptyList()列定义列表
batchActionsList<BatchAction>emptyList()批量操作定义列表
rowHeightFloat48f数据行高度
themeTableThemeDEFAULT表格主题
actionBarHeightFloat56f批量操作栏高度
actionBarBackgroundColorColor#E3F2FD操作栏背景色
actionBarTextColorColor#333333操作栏文字颜色
actionButtonTextColorColor#4A90D9操作按钮文字颜色
cancelButtonTextColorColor#999999取消按钮文字颜色
tableInit(TableView<T>.() -> Unit)?null额外表格配置回调

BatchAction 定义

参数类型默认值说明
labelString—操作标签文本
iconString?null操作图标文本（可选）
onClick(Set<Int>) -> Unit{}点击回调，参数为选中行索引集合

事件回调

事件参数说明
batchAction(BatchAction, Set<Int>)批量操作执行时触发
selectionChangedSet<Int>选中行变化时触发

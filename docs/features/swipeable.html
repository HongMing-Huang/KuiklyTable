滑动操作

SwipeableTable 在表格最右侧自动追加一个"操作"列，为每行渲染可点击的操作按钮。 通过 SwipeAction 定义操作项（标签、颜色、图标），并使用 actionBinder 将操作绑定到具体数据项。

基础用法

定义滑动操作列表，每行右侧自动出现操作按钮：

data class Student(val name: String, val score: Int)

SwipeableTable<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f) { it.name },
            column("成绩", flex = 1f, align = TableCellAlign.RIGHT) { it.score.toString() },
        )
        data = students
        swipeActions = listOf(
            SwipeAction("编辑", color = Color(0xFF4A90D9)) {},
            SwipeAction("删除", color = Color(0xFFFF4444)) {},
        )
        actionBinder = { student, action ->
            when (action.label) {
                "编辑" -> println("编辑: ${student.name}")
                "删除" -> println("删除: ${student.name}")
            }
        }
    }
}

自定义按钮宽度

通过 actionButtonWidth 控制每个操作按钮的宽度：

SwipeableTable<Student> {
    attr {
        columns = studentColumns
        data = students
        actionButtonWidth = 80f  // 每个按钮 80px 宽
        swipeActions = listOf(
            SwipeAction("置顶", color = Color(0xFFFF9800)) {},
            SwipeAction("标记", color = Color(0xFF4CAF50)) {},
            SwipeAction("删除", color = Color(0xFFFF4444)) {},
        )
        actionBinder = { student, action ->
            println("${action.label}: ${student.name}")
        }
    }
}

配合表格样式

通过 tableInit 对内部表格设置主题等额外属性：

SwipeableTable<Student> {
    attr {
        columns = studentColumns
        data = students
        rowHeight = 52f
        swipeActions = listOf(
            SwipeAction("编辑", color = Color(0xFF2196F3)) {},
            SwipeAction("删除", color = Color(0xFFE53935)) {},
        )
        actionBinder = { student, action ->
            when (action.label) {
                "编辑" -> viewModel.editStudent(student)
                "删除" -> viewModel.deleteStudent(student)
            }
        }
        tableInit = {
            attr {
                theme = TableTheme.STRIPE
            }
            event {
                rowClick { item, index ->
                    println("点击行: ${item.name}")
                }
            }
        }
    }
}

API 参考

属性类型默认值说明
dataList<T>emptyList()数据列表
columnsList<TableColumn<T>>emptyList()列定义列表
swipeActionsList<SwipeAction>emptyList()滑动操作列表
actionButtonWidthFloat72f每个操作按钮宽度
rowHeightFloat48f数据行高度
actionBinder((T, SwipeAction) -> Unit)?null将操作绑定到数据项的回调
tableInit(TableView<T>.() -> Unit)?null额外表格配置回调

SwipeAction 定义

参数类型默认值说明
labelString—操作标签文本
colorColor#FF4444操作按钮背景色
iconString?null操作图标文本（可选）
onClick() -> Unit{}点击回调（无参数，actionBinder 优先）

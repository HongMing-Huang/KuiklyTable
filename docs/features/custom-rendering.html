自定义渲染

通过 columnRenderer() 函数，你可以在单元格内嵌入任意 KuiklyUI 组件——图片、按钮、进度条、标签等， 实现远超纯文本的丰富展示效果。columnRenderer 与 column 可混合使用。

基础用法

使用 columnRenderer 在单元格中渲染图片和状态标签：

data class Student(val name: String, val avatarUrl: String, val score: Int)

val columns = listOf(
    columnRenderer<Student>("头像", flex = 1f) { student ->
        Image { attr { url(student.avatarUrl); size(32f, 32f) } }
    },
    column<Student>("姓名", flex = 2f) { it.name },
    columnRenderer<Student>("状态", flex = 1f) { student ->
        View {
            attr {
                backgroundColor(
                    if (student.score >= 60) Color(0xFF4CAF50) else Color(0xFFFF4444)
                )
                padding(4f, 8f, 4f, 8f)
                cornerRadius(4f)
            }
            Text {
                attr {
                    text(if (student.score >= 60) "及格" else "不及格")
                    color(Color.WHITE)
                    fontSize(12f)
                }
            }
        }
    }
)

Table<Student> {
    attr {
        columns = columns
        data = students
        theme = TableTheme.BORDERED
    }
}

渲染操作按钮

在最后一列渲染"编辑"和"删除"按钮，实现行级操作：

val columns = listOf(
    column<Student>("姓名", flex = 2f) { it.name },
    column<Student>("成绩", flex = 1f) { it.score.toString() },
    columnRenderer<Student>("操作", flex = 1f, align = TableCellAlign.CENTER) { student ->
        View {
            attr { flexDirectionRow() }
            Text {
                attr {
                    text("编辑")
                    color(Color(0xFF4A90D9))
                    fontSize(13f)
                    padding(4f, 8f, 4f, 8f)
                }
                event { click { println("编辑: ${student.name}") } }
            }
            Text {
                attr {
                    text("删除")
                    color(Color(0xFFFF4444))
                    fontSize(13f)
                    padding(4f, 8f, 4f, 8f)
                }
                event { click { println("删除: ${student.name}") } }
            }
        }
    }
)

进度条渲染

使用 columnRenderer 渲染进度条，直观展示数值比例：

columnRenderer<Student>("完成度", flex = 2f) { student ->
    val progress = student.score / 100f
    View {
        attr {
            flexDirectionRow()
            alignItemsCenter()
            flex(1f)
        }
        // 进度条背景
        View {
            attr {
                flex(1f)
                height(8f)
                backgroundColor(Color(0xFFEEEEEE))
                cornerRadius(4f)
            }
            // 进度条填充
            View {
                attr {
                    width(progress * 100f)
                    height(8f)
                    backgroundColor(Color(0xFF4CAF50))
                    cornerRadius(4f)
                }
            }
        }
        Text {
            attr {
                text("${student.score}%")
                fontSize(12f)
                marginLeft(8f)
            }
        }
    }
}

API 参考

参数类型默认值说明
titleString—列标题文本
flexFloat1f弹性比例，控制列宽分配
keyStringtitle列唯一标识，用于排序等功能
minWidthFloat0f最小宽度（像素）
alignTableCellAlignLEFT单元格对齐方式
sortableBooleanfalse是否允许按此列排序
comparator((T, T) -> Int)?null自定义排序比较函数
rendererViewContainer.(T) -> Unit—自定义渲染函数，在单元格容器内自由布局

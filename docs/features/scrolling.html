双向滚动

当列数较多、总宽度超出容器时，开启 horizontalScroll 即可实现横向滚动。 配合 minTableWidth 可控制表格最小宽度，确保列不会被过度压缩。 表头默认吸顶（stickyHeader = true），纵向滚动时表头始终可见。

基础用法

设置 horizontalScroll = true，为多列表格启用横向滚动：

data class Employee(
    val id: Int, val name: String, val department: String,
    val email: String, val phone: String, val salary: Int
)

Table<Employee> {
    attr {
        columns = listOf(
            column("ID", flex = 1f, minWidth = 60f) { it.id.toString() },
            column("姓名", flex = 2f, minWidth = 100f) { it.name },
            column("部门", flex = 2f, minWidth = 120f) { it.department },
            column("邮箱", flex = 3f, minWidth = 200f) { it.email },
            column("电话", flex = 2f, minWidth = 140f) { it.phone },
            column("薪资", flex = 1f, minWidth = 80f, align = TableCellAlign.RIGHT) { it.salary.toString() },
        )
        data = employees
        horizontalScroll = true
        minTableWidth = 800f
        theme = TableTheme.BORDERED
    }
}

配合排序使用

横向滚动模式下同样支持列排序，表头随横向滚动同步移动：

Table<Employee> {
    attr {
        columns = listOf(
            column("ID", flex = 1f, minWidth = 60f, sortable = true) { it.id.toString() },
            column("姓名", flex = 2f, minWidth = 100f, sortable = true) { it.name },
            column("部门", flex = 2f, minWidth = 120f) { it.department },
            column("邮箱", flex = 3f, minWidth = 200f) { it.email },
            column("薪资", flex = 1f, minWidth = 80f, sortable = true,
                comparator = { a, b -> a.salary.compareTo(b.salary) }
            ) { it.salary.toString() },
        )
        data = employees
        horizontalScroll = true
        minTableWidth = 700f
        sortable = true
        stickyHeader = true
    }
}

自定义最小宽度

minTableWidth 设为 0f（默认值）时，表格宽度由各列的 flex 和 minWidth 自动计算。 显式设置可确保表格不会因容器过窄而压缩列宽： 

Table<Employee> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f, minWidth = 120f) { it.name },
            column("部门", flex = 1f, minWidth = 100f) { it.department },
            column("邮箱", flex = 3f, minWidth = 240f) { it.email },
        )
        data = employees
        horizontalScroll = true
        minTableWidth = 600f  // 表格内容区至少 600px 宽
    }
}

4 种内置主题

KuiklyTable 内置 4 种开箱即用的主题风格，通过 theme 属性一行切换， 无需手动编写样式。所有颜色、边框、分隔线均可通过 TableAttr 进一步自定义。

DEFAULT — 默认主题

仅底部分隔线，简洁大方，适合大部分数据展示场景。

Table<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f) { it.name },
            column("成绩", flex = 1f) { it.score.toString() },
        )
        data = students
        theme = TableTheme.DEFAULT  // 可省略，DEFAULT 为默认值
    }
}

STRIPE — 斑马纹主题

奇偶行交替背景色，提升大数据量下的行可读性。偶数行颜色由 stripeRowBackgroundColor 控制。

Table<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f) { it.name },
            column("年龄", flex = 1f) { it.age.toString() },
            column("成绩", flex = 1f) { it.score.toString() },
        )
        data = students
        theme = TableTheme.STRIPE
        // 可选：自定义斑马纹偶数行背景色
        // stripeRowBackgroundColor = Color(0xFFF0F4FF)
    }
}

BORDERED — 全边框主题

每个单元格都有完整边框，适合数据密集型、财务报表等需要清晰分隔的场景。

Table<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f) { it.name },
            column("年龄", flex = 1f, align = TableCellAlign.CENTER) { it.age.toString() },
            column("成绩", flex = 1f, align = TableCellAlign.RIGHT) { it.score.toString() },
            column("年级", flex = 1f) { it.grade },
        )
        data = students
        theme = TableTheme.BORDERED
        // 可选：自定义边框颜色和宽度
        // borderColor = Color(0xFFCCCCCC)
        // borderWidth = 1f
    }
}

MINIMAL — 极简主题

无边框、无分隔线，极简风格，适合卡片式布局或与其他 UI 组件嵌套使用。

Table<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f) { it.name },
            column("成绩", flex = 1f) { it.score.toString() },
        )
        data = students
        theme = TableTheme.MINIMAL
    }
}

主题对比一览

| 主题 | 分隔线 | 边框 | 适用场景 |
|------|--------|------|----------|
| DEFAULT | ✅ 底部 | ❌ | 通用列表、信息展示 |
| STRIPE | ✅ 底部 | ❌ | 大数据量、财务报表 |
| BORDERED | ✅ | ✅ 全边框 | 数据密集型、Excel 风格 |
| MINIMAL | ❌ | ❌ | 卡片嵌套、极简设计 |

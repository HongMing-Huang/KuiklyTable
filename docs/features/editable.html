内联编辑

EditableTable 支持对指定列进行单元格内联编辑。点击或双击行（由 EditTrigger 控制） 进入编辑态后，显示 Input 输入框及确认/取消按钮。编辑完成后通过 onSave 回调获取新值。

基础用法

指定可编辑列的 key 集合，设置保存回调：

data class Student(val name: String, val age: Int, val score: Int)

EditableTable<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f, key = "姓名") { it.name },
            column("年龄", flex = 1f, key = "年龄") { it.age.toString() },
            column("成绩", flex = 1f, key = "成绩") { it.score.toString() },
        )
        data = students.toMutableList()
        editableColumns = setOf("姓名", "成绩")  // 只允许编辑姓名和成绩
        editTrigger = EditTrigger.DOUBLE_CLICK   // 双击触发编辑
        onSave = { item, index, columnKey, newValue ->
            when (columnKey) {
                "姓名" -> students[index] = item.copy(name = newValue)
                "成绩" -> students[index] = item.copy(score = newValue.toIntOrNull() ?: 0)
            }
            students[index]  // 返回更新后的数据项
        }
    }
}

单击触发编辑

将 editTrigger 设为 CLICK，单击行即可进入编辑态：

EditableTable<Student> {
    attr {
        columns = studentColumns
        data = students
        editableColumns = setOf("姓名", "年龄", "成绩")
        editTrigger = EditTrigger.CLICK  // 单击触发
        onSave = { item, index, columnKey, newValue ->
            println("编辑行 $index, 列 $columnKey, 新值: $newValue")
            item  // 返回原数据项或更新后的副本
        }
    }
    event {
        editStart { index, columnKey ->
            println("开始编辑: 行 $index, 列 $columnKey")
        }
        editEnd { index, columnKey ->
            println("结束编辑: 行 $index, 列 $columnKey")
        }
    }
}

配合表格样式

通过 tableInit 对内部表格设置主题等额外属性：

EditableTable<Student> {
    attr {
        columns = studentColumns
        data = students
        editableColumns = setOf("姓名", "成绩")
        cellFontSize = 14f
        cellTextColor = Color(0xFF333333)
        tableInit = {
            attr {
                theme = TableTheme.BORDERED
            }
        }
        onSave = { item, index, columnKey, newValue ->
            // 处理保存逻辑
            item
        }
    }
}

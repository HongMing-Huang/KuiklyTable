树形表格

树形表格用于展示具有层级关系的数据，例如组织架构、文件目录、分类体系等。 使用 TreeNode 描述节点结构，TreeTable DSL 渲染层级行，支持点击展开/折叠子节点。

基础树形结构

定义数据节点类，用 TreeNode 包装父子关系：

data class OrgNode(val name: String, val leader: String = "", val count: Int = 0)

val treeData = listOf(
    TreeNode(OrgNode("总公司", "王总", 500), children = listOf(
        TreeNode(OrgNode("技术部", "张经理", 120), children = listOf(
            TreeNode(OrgNode("前端组", "李组长", 30)),
            TreeNode(OrgNode("后端组", "赵组长", 45)),
            TreeNode(OrgNode("测试组", "孙组长", 20)),
        )),
        TreeNode(OrgNode("市场部", "刘经理", 80), children = listOf(
            TreeNode(OrgNode("品牌组", "陈组长", 25)),
            TreeNode(OrgNode("渠道组", "周组长", 30)),
        )),
        TreeNode(OrgNode("财务部", "吴经理", 40)),
    ))
)

TreeTable DSL 渲染

使用 TreeTable<T> DSL，传入 treeData 和列配置：

TreeTable<OrgNode> {
    attr {
        treeData = listOf(
            TreeNode(OrgNode("总公司", "王总", 500), children = listOf(
                TreeNode(OrgNode("技术部", "张经理", 120), children = listOf(
                    TreeNode(OrgNode("前端组", "李组长", 30)),
                    TreeNode(OrgNode("后端组", "赵组长", 45)),
                )),
                TreeNode(OrgNode("市场部", "刘经理", 80)),
            ))
        )
        columns = listOf(
            column("名称", flex = 3f) { it.name },
            column("负责人", flex = 1f) { it.leader },
            column("人数", flex = 1f, align = TableCellAlign.RIGHT) { it.count.toString() },
        )
        theme = TableTheme.DEFAULT
    }
}

配合排序使用

树形表格同样支持列排序，在展开的子节点范围内按指定列排序：

TreeTable<OrgNode> {
    attr {
        treeData = orgTree
        columns = listOf(
            column("名称", flex = 3f, sortable = true) { it.name },
            column("人数", flex = 1f, sortable = true,
                comparator = { a, b -> a.count.compareTo(b.count) }
            ) { it.count.toString() },
        )
        sortable = true
    }
    event {
        rowClick { item, _ ->
            println("点击节点：${item.name}，人数：${item.count}")
        }
    }
}

TreeNode 结构说明

TreeNode(data, children)：包装一个数据项及其子节点列表。
data：当前节点的业务数据对象。
children：子节点列表，类型为 List<TreeNode<T>>，空列表表示叶子节点。
树形表格自动根据 children 是否为空来判断是否显示展开/折叠图标。

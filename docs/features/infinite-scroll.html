无限滚动

InfiniteTable 支持滚动到底部自动加载更多数据。内部包装 TableView， 在表格底部显示"加载中"指示器或"没有更多了"提示。外部通过 appendData 追加新数据。

基础用法

设置初始数据、加载阈值和是否还有更多数据，注册 onLoadMore 回调：

data class Student(val name: String, val score: Int)

InfiniteTable<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f) { it.name },
            column("成绩", flex = 1f, align = TableCellAlign.RIGHT) { it.score.toString() },
        )
        data = initialStudents  // 初始 20 条数据
        loadThreshold = 5       // 距离底部 5 行时触发加载
        hasMore = true          // 还有更多数据
    }
    event {
        onLoadMore = {
            // 异步加载下一页数据后调用 appendData
            val nextPage = fetchNextPage()
            appendData(nextPage)
            if (nextPage.size < 20) {
                // 数据不足一页，标记无更多数据
                attr.hasMore = false
            }
        }
    }
}

自定义提示文案

通过 loadingText 和 noMoreText 自定义加载状态提示：

InfiniteTable<Student> {
    attr {
        columns = studentColumns
        data = initialStudents
        loadingText = "正在加载更多数据..."
        noMoreText = "— 已加载全部 —"
        hasMore = true
        loadThreshold = 3
    }
    event {
        onLoadMore = {
            coroutineScope.launch {
                val data = api.fetchStudents(page = currentPage + 1)
                appendData(data)
                currentPage++
            }
        }
    }
}

配合表格主题

通过 tableInit 对内部表格设置主题、排序等属性：

InfiniteTable<Student> {
    attr {
        columns = studentColumns
        data = initialStudents
        hasMore = true
        tableInit = {
            attr {
                theme = TableTheme.STRIPE
                sortable = true
            }
            event {
                rowClick { item, index ->
                    println("点击: ${item.name}")
                }
            }
        }
    }
}

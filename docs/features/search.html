搜索过滤

FilterableTable 在表格顶部渲染搜索输入栏，下方表格自动根据关键词过滤显示数据。 支持自定义匹配逻辑（filterExtractor），也可省略让组件自动使用所有列的文本提取器进行模糊匹配。

基础用法

传入数据和列定义，设置搜索占位文本即可。默认会匹配所有列的文本内容：

data class Student(val name: String, val id: String, val score: Int)

FilterableTable<Student> {
    attr {
        data = allStudents
        columns = listOf(
            column("姓名", flex = 2f) { it.name },
            column("学号", flex = 1f) { it.id },
            column("成绩", flex = 1f, align = TableCellAlign.RIGHT) { it.score.toString() },
        )
        searchPlaceholder = "搜索学生姓名或学号..."
    }
}

自定义过滤逻辑

通过 filterExtractor 自定义匹配规则，例如同时匹配多个字段：

FilterableTable<Student> {
    attr {
        data = allStudents
        columns = studentColumns
        searchPlaceholder = "输入关键词搜索..."
        filterExtractor = { student, keyword ->
            val kw = keyword.lowercase()
            student.name.lowercase().contains(kw) ||
                student.id.lowercase().contains(kw) ||
                student.score.toString().contains(kw)
        }
    }
    event {
        keywordChanged { kw -> println("搜索关键词: $kw") }
        filterResultChanged { count -> println("匹配到 $count 条数据") }
    }
}

配合表格样式

通过 tableInit 对内部表格设置主题、排序等额外属性：

FilterableTable<Student> {
    attr {
        data = allStudents
        columns = studentColumns
        searchPlaceholder = "搜索..."
        searchBarBackgroundColor = Color(0xFFF0F4FF)
        tableInit = {
            attr {
                theme = TableTheme.STRIPE
                sortable = true
            }
        }
    }
}

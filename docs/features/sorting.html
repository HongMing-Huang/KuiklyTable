排序

KuiklyTable 内置三态循环排序：点击表头列标题，依次循环 无排序 → 升序 → 降序。 支持为每列指定自定义 comparator，实现数值、日期等复杂类型的精确排序。

基础排序

为需要排序的列设置 sortable = true，并在 attr {} 中开启全局 sortable：

data class Student(val name: String, val age: Int, val score: Int)

val students = listOf(
    Student("张三", 18, 92),
    Student("李四", 17, 85),
    Student("王五", 16, 78),
    Student("赵六", 18, 95),
)

Table<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f, sortable = true) { it.name },
            column("年龄", flex = 1f, sortable = true) { it.age.toString() },
            column("成绩", flex = 1f, sortable = true) { it.score.toString() },
        )
        data = students
        sortable = true
        theme = TableTheme.DEFAULT
    }
}

自定义 comparator

默认按文本字典序排序。对数值类型，传入 comparator 参数实现精确比较： 

Table<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f, sortable = true) { it.name },
            column("年龄", flex = 1f, sortable = true,
                comparator = { a, b -> a.age.compareTo(b.age) }
            ) { it.age.toString() },
            column("成绩", flex = 1f, sortable = true,
                comparator = { a, b -> a.score.compareTo(b.score) }
            ) { it.score.toString() },
        )
        data = students
        sortable = true
    }
}

监听排序变化

通过 event {} 中的 sortChanged 回调获取当前排序状态：

Table<Student> {
    attr {
        columns = listOf(
            column("姓名", flex = 2f, sortable = true) { it.name },
            column("成绩", flex = 1f, sortable = true,
                comparator = { a, b -> a.score.compareTo(b.score) }
            ) { it.score.toString() },
        )
        data = students
        sortable = true
    }
    event {
        sortChanged { state ->
            // state.columnKey — 排序列的 key
            // state.ascending  — true 为升序，false 为降序
            println("排序列: ${state.columnKey}")
            println("方向: ${if (state.ascending) "升序" else "降序"}")
        }
    }
}

SortState 说明

columnKey：当前排序列的标识，对应 column() 创建时的 key 参数（默认取 title）。
ascending：布尔值，true 表示升序，false 表示降序。

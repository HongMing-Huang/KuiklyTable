空状态

TableWithEmptyState 包装了 TableView，根据 isEmpty 属性条件渲染： 有数据时显示表格，无数据时显示友好的空状态占位视图（可选图标 + 提示文案）。

基础用法

传入 isEmpty 判断条件，设置空状态提示文案：

data class Student(val name: String, val score: Int)

val students: List<Student> = emptyList()  // 当前无数据

TableWithEmptyState<Student> {
    attr {
        isEmpty = students.isEmpty()
        emptyText = "暂无学生数据"
        emptyIcon = "📋"
        tableInit = {
            attr {
                columns = listOf(
                    column("姓名", flex = 2f) { it.name },
                    column("成绩", flex = 1f) { it.score.toString() },
                )
                data = students
                theme = TableTheme.BORDERED
            }
        }
    }
}

自定义空状态样式

通过样式属性自定义空状态的颜色、字号和容器高度：

TableWithEmptyState<Student> {
    attr {
        isEmpty = students.isEmpty()
        emptyText = "还没有数据，快去添加吧！"
        emptyTextColor = Color(0xFFAAAAAA)
        emptyTextSize = 16f
        emptyIcon = "📭"
        containerHeight = 300f
        tableInit = {
            attr {
                columns = studentColumns
                data = students
            }
        }
    }
}

动态切换

根据数据加载状态动态显示表格或空状态：

// ViewModel 中
var students: List<Student> by observable(emptyList())

// 视图中
TableWithEmptyState<Student> {
    attr {
        isEmpty = students.isEmpty()
        emptyText = if (isLoading) "加载中..." else "暂无数据"
        emptyIcon = if (isLoading) "⏳" else "📭"
        tableInit = {
            attr {
                columns = studentColumns
                data = students
                theme = TableTheme.STRIPE
            }
        }
    }
}

API 参考

属性类型默认值说明
isEmptyBooleanfalse是否为空状态，由外部根据数据判断
emptyTextString"暂无数据"空状态提示文案
emptyTextColorColor#999999空状态文案颜色
emptyTextSizeFloat14f空状态文案字号
emptyIconString?null空状态图标文本（可选），显示在文案上方
containerHeightFloat400f容器高度
tableInit(TableView<T>.() -> Unit)?null内部表格初始化回调，null 时不渲染表格
